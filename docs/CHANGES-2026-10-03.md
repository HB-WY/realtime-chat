# 变更说明 · 2026-10-03

## 新增功能

### 1. 个性签名（signature）

- **数据库**：`users` 表新增 `signature TEXT NOT NULL DEFAULT ''` 列。
  老库启动时自动迁移（`schema.js` 的 `addCol`），无需手工改库。
- **配置**：`config.yaml → business.user.signature.max_len = 60`，
  `config.js` 带默认值兜底。
- **API**：
  - `PATCH /api/me` 接受 `signature` 字段（trim + 长度校验，可传空串清除）；
  - 新增 `GET /api/users/:id` —— 返回任意用户公开资料
    `{ id, username, nickname, avatar, signature }`（需登录，用户卡片用）。
- **下发点同步**：登录 / 注册 / 刷新 token / `GET /api/auth/me` /
  `GET /api/friends` / socket `state:init`（user + friends）/
  `friend:list` / `user:updated` 广播，全部带上 `signature`。
  （`user:updated` 与在线列表仍刻意**不含 username**，安全策略不变。）
- **客户端**：
  - 个人信息页（AvatarEditor）新增「个性签名」多行输入框（60 字）；
  - `App.jsx` 的 `onUserUpdate` 比较补上 signature。

### 2. 好友常驻消息栏

- `ChatRoom.jsx` 新增 `mergeFriendRooms(prevRooms, friends, meId)`：
  - 每个好友固定对应一个私聊会话，**不管在不在线、有没有聊过**，
    初始化（`state:init`）与好友变动（`friend:list`）时都会合并进会话列表；
  - 加好友 → 自动补建「暂无消息」会话；
  - 删好友 → 空会话移除，**有聊天记录的会话保留**（微信行为）。
- 消息栏（RoomList）：
  - 没聊过天的好友会话摘要显示**对方个性签名**（`roomPreview`）；
  - 好友会话显示在线状态小圆点（在线绿 / 离线灰，与会话常驻无关）。
- 私聊头部（ChatHeader）展示对端签名（超长省略）。

### 3. 点击头像弹出用户卡片

- 新组件 `client/src/components/common/UserCardModal.jsx`：
  - 大头像 + 昵称 + 在线状态 + `@username` + 个性签名；
  - 【私信】按钮 → 复用 `openPrivateChat` 直接打开私聊；
  - 【加好友】按钮 → `socket 'friend:request'`（已是好友显示「已是好友」，
    自己显示「这是我自己」）；
  - 数据优先用本地（friends / 自己），再请求 `GET /api/users/:id` 拉最新。
- 可点击头像的位置：
  - 聊天消息里的头像（MessageBubble，公共 / 群聊 / 私聊通用）；
  - 消息栏里私聊会话的头像；
  - 联系人列表里好友的头像；
  - 私聊聊天头部的头像与昵称。
- `Avatar` 组件本身未改，外层包 `.avatar-click` 交互壳（hover 放大）。
